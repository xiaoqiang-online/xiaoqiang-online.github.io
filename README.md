## 语文
### 修饰手法
#### 比喻：本体、喻体、比喻词
春天像个害羞的小姑娘，遮遮掩掩躲躲藏藏。
#### 拟人：直接把东西当做人
春天有点害羞，遮遮掩掩躲躲藏藏。
#### 赏析语句（4分）
看吧，山上的矮松越发的青黑，树尖儿上顶着一髻儿白花，好像日本看护妇。------老舍《济南的冬天》
第1分：用了比喻的修饰手法。第2分：把顶着白花的矮松比作日本的看护妇。第3分：表面上凸显矮松的矮小，内在上温柔温顺秀气。第4分：白花，直接把雪花比喻作白花，借喻。
